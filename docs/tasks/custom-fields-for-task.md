# Custom Fields

Custom Fields in FluentBoards allow you to add task-specific information tailored to your workflow. Whether it's a text note, a number, a deadline, priority level, or any other detail, Custom Fields make your Task Board more flexible and personalized.

This guide walks you through how to **create**, **manage**, and **customize** fields to suit your project needs.

## Add New Custom Field

To create a new custom field, go to **Task Actions** and click on the **Custom Field** button.

![task action 01](../public/images/task-management/custom-fields-for-task/Task-Action-01-scaled.webp)

A pop-up will appear. Click the **+ Add New Custom Field** button.

![add new custom field 02](../public/images/task-management/custom-fields-for-task/add-new-custom-field-02-scaled.webp)

In the new pop-up window, enter a **Title** for your field and select a **Field Type** from the dropdown menu.

Once done, click the **Add Custom Field** button to create the new field.

After saving, the custom field will appear on the left side of your **Task Board** under the task details panel.

![unnamed](../public/images/task-management/custom-fields-for-task/unnamed.webp)

## Field Type

FluentBoards supports several field types, each offering different ways to input and display data. Below is a detail of the available types:

**Text:** Select **Text** if you want to add simple text-based input.

After adding a **Text** field, the custom field will appear on the left side of your **Task Board**. To edit the field, click on the field's **Title** on the right side.

![text field 03](../public/images/task-management/custom-fields-for-task/text-field-03-1-scaled.webp)

You can update the title and click **Update Custom Field** to save changes. To remove it, click the **Delete Custom Field** button.

![unnamed (1)](../public/images/task-management/custom-fields-for-task/unnamed-1.webp)

**Number:** Choose the **Number** type to add numerical input. The field will appear in the task’s custom field area, ready for numeric values.

![nuber field 04](../public/images/task-management/custom-fields-for-task/nuber-field-04-scaled.webp)

**Select:** Use the **Select** type when you want users to choose one option from a list.

Click the **+ Add Option** button to add choices. The field appears as a dropdown in the task.

![select type 05](../public/images/task-management/custom-fields-for-task/select-type-05-scaled.webp)

**Multi-Select:** Choose **Multi-Select** if users need to select more than one option.

You can add multiple choices using the **+ Add Option** button.

![multi select 06](../public/images/task-management/custom-fields-for-task/Multi-select-06-scaled.webp)

**Date:** The **Date** type lets you assign a specific calendar date.

A calendar picker appears in the task for easy selection.

![date custom field 07](../public/images/task-management/custom-fields-for-task/Date-custom-field-07-scaled.webp)

**Checkbox Field:** If you want to add a checkbox option, select the **Checkbox** field type. This field appears as a **single checkbox** on the task.

![checkbox field 08](../public/images/task-management/custom-fields-for-task/checkbox-field-08-scaled.webp)
